Job Title: Junior Data Scientist

About the Role:
We are looking for a Junior Data Scientist to join our analytics team. You will work
on cleaning and analyzing data, building machine learning models, and communicating
insights to stakeholders through clear visualizations and reports.

Responsibilities:
- Perform data collection, cleaning, and preprocessing using Python
- Conduct exploratory data analysis (EDA) to identify trends and patterns
- Build and evaluate machine learning models for prediction and classification tasks
- Create dashboards and visualizations to communicate findings to stakeholders
- Write SQL queries to extract and analyze data from relational databases
- Collaborate with cross-functional teams to translate business problems into
  data-driven solutions

Requirements:
- 1-3 years of experience in data analysis or data science (internships count)
- Strong proficiency in Python, Pandas, NumPy, and Scikit-learn
- Experience with data visualization tools such as Power BI, Tableau, Matplotlib, or Seaborn
- Working knowledge of SQL and relational databases
- Understanding of core machine learning concepts: regression, classification, model
  evaluation metrics (accuracy, F1-score, confusion matrix)
- Familiarity with Git for version control
- Bachelor's degree in Computer Science, Data Science, Statistics, or a related field
- Strong communication skills and ability to explain technical findings to
  non-technical stakeholders

Nice to Have:
- Experience with Streamlit or similar tools for building interactive demos
- Exposure to cloud platforms (AWS, Azure, GCP)
- Experience with deep learning frameworks (TensorFlow, PyTorch)
